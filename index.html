The science underneath

Built by people who build with AI, and know where it breaks.

These aren't prompt-writing exercises. Each simulation is engineered around a real failure mode of AI systems, and the data is built so that blind trust gets caught.

Sealed outcomes

What actually happened stays locked until participants commit. No hindsight, no gaming.

Blind rounds

Learning is tested on a book the agents have never seen, so overfitting shows up.

Hard limits

Budgets, caps and policy sit outside the agents. No prompt and no learning can move them.

Planted failure modes

Models that are wrong for one group, drifting data and agents blind to the limits wait to be found.

The precision standard participants are graded on

Every rule states its intent and carries the exact test. If a stranger and a machine could act differently, the rule fails.

FAILSDo not waste vouchers on loyal customers.
PASSESDo not send any voucher to a customer whose return is below 2.0, because the expected margin saved would be less than twice the voucher value.
FAILSWatch out for bad data.
PASSESBlock any file in which pred_lapse_prob is below 0 or above 1 on any row, because a probability outside that range is impossible.

Questions

Before you ask.

Do participants need to code?

No. Participants write agent instructions in plain language and reason about limits and outcomes. Teams that want to build the agents in code can do so with the same data.

Which AI tools do the desks work with?

The desks are tool-agnostic. Participants can run their committee in any capable AI assistant or agent framework. The learning is in the design, the limits and the checking, not in a specific product.

How long does a desk take?

Beginner desks run in a single 3 to 5 hour session. Advanced desks such as the Customer Growth Committee run over several rounds, up to 16 to 20 hours.

Are the companies and data real?

All companies and records are fictional, built to behave like real business data, with planted problems for participants to find.

How do we license a desk?

Write to us with your institution or firm, your audience size and the desks you're interested in. Packs are shared on request, with licensing for courses, cohorts and corporate programmes.
